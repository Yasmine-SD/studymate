# StudyMate — AI Tutor Chatbot

A patient AI tutor for Machine Learning, Deep Learning & LLMs.
Fine-tuned GPT-2 Medium to respond in a consistent tutor style.

## Links
- **Demo:** https://huggingface.co/spaces/yasminesd/studymate
- **Model:** https://huggingface.co/yasminesd/studymate-gpt2

## Stack
- Model: GPT-2 Medium (345M parameters)
- Fine-tuning: PyTorch + AdamW
- Interface: Gradio
- Deployment: HuggingFace Spaces

##  Files
- `notebook.ipynb` — Dataset + Fine-tuning code
- `app.py` — Gradio interface
